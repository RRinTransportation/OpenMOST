# Analysis

Both analyses read the paper-level dataset from
`../zenodo/analysis_dataset/` (download `analysis_dataset.zip` from Zenodo
first; see [`../zenodo/README.md`](../zenodo/README.md)).

| Folder | Description | Author | Tooling |
|---|---|---|---|
| [`choice-models/`](choice-models) | Discrete choice (logit) models predicting data and code availability, estimated with Biogeme | Silvia Varotto | Python, uv, Jupyter |
| [`descriptive-statistics-and-bivariate-tests/`](descriptive-statistics-and-bivariate-tests) | Descriptive statistics, bivariate tests, and an interactive Shiny data explorer | Gregory S. Macfarlane | R, renv, Quarto, Shiny |

See each folder's README for setup and run instructions.
